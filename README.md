# Book Genre Text Analysis

This project analyzes books from several literary genres using Python and natural language processing techniques. The goal is to clean and process raw book text, extract useful text features, and compare patterns across different genres.

## Genres

The dataset contains books from four genres:

- Mystery / Detective
- Horror / Gothic
- Adventure
- Science Fiction

The original books are stored as `.txt` files inside the `books/` directory and organized by genre.

## Running the Project

### Requirements

The project uses Python and common data-analysis libraries such as:

```text
pandas
numpy
matplotlib
re
```

Additional libraries may be required depending on the text-analysis methods used later in the notebook.

### Run

1. Download or clone the project folder.
2. Make sure the `books/` directory remains in the same location relative to the notebook.
3. Open the project directory in Jupyter Notebook.
4. Open the main `.ipynb` notebook.
5. Run the notebook cells in order from top to bottom.

The notebook loads the raw `.txt` files from the `books/` directory, cleans and processes the text, and performs the analysis.
